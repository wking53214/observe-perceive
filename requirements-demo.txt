# Packages for examples/cns_governed_decision_demo.py, the demo of the optional
# CNS combining layer (cns_governed_decision.py).
#
# Use a scratch virtual environment, then run the demo from the repository root:
#   pip install -r requirements-demo.txt
#   PYTHONPATH=. python examples/cns_governed_decision_demo.py
# Do not install observe-perceive itself into the same environment: its
# pyproject pins older commits of some of these libraries. The demo imports
# only the flat module cns_governed_decision, which needs nothing but CNS.
#
# The libraries are installed from exact commits, so a later push to a branch
# cannot change what gets installed. Governance Gateway, CCC, DIT and the
# Conservation Kernel are at the commits on their main branches whose own [cns]
# extras pin CNS v1.9.0 (2026-10-21), so they agree with the CNS line below and
# pip can resolve the set.
#
# AUGUR is the exception. Its main branch no longer carries code, so it stays at
# the commit below, whose [cns] extra pins CNS v1.4.0, which cannot be installed
# together with v1.9.0. It is installed without that extra. Its
# connector imports cns only when used, and gets the CNS installed here.
#
# CNS is pinned to the tag v1.9.0.
