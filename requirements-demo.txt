# Packages for examples/cns_governed_decision_demo.py, the demo of the optional
# CNS combining layer (cns_governed_decision.py).
#
# Use a scratch virtual environment, then run the demo from the repository root:
#   pip install -r requirements-demo.txt
#   PYTHONPATH=. python examples/cns_governed_decision_demo.py
# Do not install observe-perceive itself into the same environment: its
# pyproject pins older commits of some of these libraries. The demo imports
# only the flat module cns_governed_decision, which needs nothing but CNS.
#
# The libraries are installed from exact commits, so a later push to a branch
# cannot change what gets installed.
#
# CNS comes from the one explicit line below, the tag v4.0.0 (commit eabe6c7).
# None of the libraries is installed with its [cns] extra. Each of these commits
# has a [cns] extra that pins an older CNS (Governance Gateway, CCC, DIT and the
# Conservation Kernel pin v2.2.0), and pip cannot install two
# CNS versions: asking for the extra made the resolver fail on 2026-10-31
# (cognitive-continuity-constitution[cns] needs cns 2.2.0, this file needs 3.0.0).
# The extra only adds the cns dependency, which is already here, and each
# library's connector imports cns only when it is used.
#
# Moving a library to a newer commit is a separate decision. The Conservation
# Kernel in particular cannot follow its main branch yet: every commit that
# pins CNS v2.3.0 also makes an evidence guard mandatory when a kernel is built.
